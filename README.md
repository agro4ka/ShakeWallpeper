# Shake Wallpaper 2.0 (несколько областей)

Сборка: открыть папку в Android Studio (Hedgehog или новее) → Sync → Build > Build APK(s).
Либо в терминале: `gradle assembleDebug` (Gradle 8.7+, JDK 17, Android SDK 34).

Что нового относительно исходного APK:
- Можно добавлять до 12 областей («Добавить область»), двигать их и менять размер (точки на краях).
- У каждой области свои настройки: чувствительность, амплитуда, длительность, скорость, касание.
- Кнопка «Применить эти настройки ко всем областям» — если нужны одинаковые.
- Зум и положение кадра общие для всей картинки. Встроенная и своя картинка, RU/EN — как раньше.

## Сборка APK без Android Studio (через GitHub)
1. Создайте бесплатный аккаунт на github.com и новый репозиторий.
2. Загрузите в него все файлы проекта (Add file → Upload files), включая папку `.github`.
3. Вкладка Actions → «Build APK» → Run workflow (или оно запустится само после загрузки).
4. Через 3–5 минут откройте завершённый запуск и скачайте архив `ShakeWallpaper-apk` — внутри `app-debug.apk`.
